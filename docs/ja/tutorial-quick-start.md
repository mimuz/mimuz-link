# チュートリアル 1：クイックスタート

ここでは、ESP32にブリッジと最低限のクライアントのプログラムを書き込んで、mimuz-link での接続を確認をします。

最低限のクライアントの機能は以下の通りです。    

- BOOT ボタンを押すと、MIDI Note ONを送信します。(Note Numberは 60)
- BOOT ボタンを離すと、MIDI Note OFFを送信します。(Note Numberは 60)
- MIDI Note ON を受信すると、LED が点灯します。
- MIDI Note OFF を受信すると、LED が消灯します。

## 用意するもの

用意するものは以下の通りです。

- ブリッジ用の **XIAO ESP32-S3**（アンテナを付けたもの）
- クライアント用の **XIAO ESP32-C6**
  - 配線は不要です。クライアントの example は、ボードに付いている BOOT ボタンとユーザー LED を使います。
- USB-C ケーブル 2 本
  - データ通信ができるものが必要です。充電専用のケーブルは使えません。
- PC
  - ブラウザーは **Chrome または Edge** を使います。この Web サイトが Web Serial と Web MIDI を使うためです。
  - [git](https://git-scm.com/) と [Node.js](https://nodejs.org/)（18 以降）が必要です。
- MIDI メッセージを確認するためのソフトウエア
  - MIDI モニター、DAW、またはこのリポジトリの Node.js 用モニター（`examples/node/monitor.mjs`、Node.js 20 以降）のいずれかを使います。
  - 音を出して確認したい場合は、ソフトウエア音源を使える DAW などが必要です（ステップ 5 を参照）。

## ステップ 1：Web サイトの起動

このリポジトリには、このチュートリアル、コンソール、ファームウエアアップローダーを表示する Web サイトが含まれています。この Web サイトを PC 上で起動します。

```sh
git clone https://github.com/mimuz/mimuz-link.git
cd mimuz-link
npm start
```

起動したら、Chrome または Edge で http://localhost:8080 を開きます。

Web Serial と Web MIDI は `https://` か `http://localhost` のページでしか使えないため、Web サイトを PC 上で動かしています。

## ステップ 2：ブリッジのファームウエアの書き込み

1. XIAO ESP32-S3 を PC に接続します。
2. **Firmware uploader** のページを開きます。**Bridge** の欄の **Restart into update mode** を押し、ボードのシリアルポートを選択します。ボードがダウンロードモードで再起動し、新しいポートとして認識されます。
   - まだ Arduino のスケッチが書き込まれていないボードや、再起動しないボードは、**BOOT** ボタンを押したまま USB に接続すると、ダウンロードモードになります。
3. **Write firmware** を押し、新しいポート（USB JTAG/serial debug unit）を選択します。
4. 書き込みが終わると、ブリッジは新しいファームウエアで再起動します。ブリッジは起動時に空いている無線チャンネルを調べるため、使えるようになるまで約 15 秒かかります。

書き込みが完了すると、PC に USB-MIDI デバイス `mi:muz:bridgeESPS3-<固有 ID>` が認識されます。このデバイスには `Port 1` から `Port 8` までの 8 つのポートがあります。

## ステップ 3：クライアントのファームウエアの書き込み

1. XIAO ESP32-C6 を PC に接続します。
2. **Firmware uploader** のページで、**Client (basic example)** の欄の **Write firmware** を押し、ボードのポート（USB JTAG/serial debug unit）を選択します。
3. 新品の XIAO ESP32-C6 は、最初の書き込みのあと、一度 USB を抜いて挿し直すまでファームウエアが動作しません。書き込みが終わったら、一度だけ挿し直してください。

ここで書き込むのは basic の example（`examples/client/basic`）で、冒頭で説明した最低限のクライアントの機能を持っています。

## ステップ 4：ペアリング

クライアントとブリッジをペアリングします。

まだペアリングしていないクライアントは、**すぐ隣にある**ブリッジ（電波の強さが -55 dBm 以上）とだけペアリングします。近くにある他の人のブリッジと、意図せずペアリングしてしまうことを防ぐためです。

1. ブリッジは PC に接続したまま、動作させておきます（ステップ 2）。
2. クライアントをブリッジのすぐ隣（数 cm）に置き、電源を入れます。PC に挿し直すか、別の USB 電源に接続します。
3. **Console** のページを開きます。ブラウザーから MIDI の使用の許可を求められたら、許可します（コンソールは、ブリッジへのコマンドを SysEx で送るためです）。ブリッジはデバイスの一覧に自動で表示されます。
4. ブリッジを選択し、**Clients** タブを開きます。クライアントが **Port 1** に、モデル `basic` として表示されていれば、ペアリングは完了です。

ペアリングすると、ブリッジはクライアントを記憶します。以降、クライアントは無線が届く範囲であればどこからでもこのブリッジに接続し、接続した時点で空いている最も小さい番号のポートを使います。

ポートはデバイスごとに固定ではなく、クライアントが接続した順番で決まります。アプリケーションからは、ポート番号ではなく、名前・ラベル・モデルでクライアントを見つけます（[チュートリアル 2](tutorial-new-client.md) を参照）。

クライアントを別のブリッジとペアリングし直す場合は、まず登録を削除します（Clients タブでクライアントのウィンドウを開いて **Unpair** を押すか、設定コマンド `unpair` を使います）。そのあと、新しいブリッジの隣でもう一度ペアリングします。

## ステップ 5：MIDI の送受信の確認

クライアントとPC の間で、MIDI メッセージが送受信できることを確認します。

basic の example は MIDI メッセージを送受信するだけで、それ自体は音を出しません。PC で音を出したい場合は、DAW などで、ブリッジの Port 1 からの入力をソフトウエア音源につないでください。

1. MIDI モニターなどのソフトウエアで、入力 **`mi:muz:bridgeESPS3-<固有 ID>` Port 1** を開きます。OS によってポート名の表示が少し異なることがありますが、ポートの番号が合っていれば問題ありません。
2. クライアントの BOOT ボタンを押すと、MIDI Note ON（チャンネル 1、Note Number 60）が届きます。ボタンを離すと、MIDI Note OFF が届きます。
3. PC から Port 1 に MIDI Note ON（Velocity は 1 以上）を送ると、クライアントの LED が点灯します。MIDI Note OFF を送ると消灯します。

このリポジトリの Node.js 用モニターを使う場合は、以下のように実行します。

```sh
cd examples/node
npm install
node monitor.mjs
```

モニターは、ブリッジとクライアントの接続や切断のたびに一覧を表示し、クライアントから届いた MIDI メッセージを 1 つずつ表示します。

```
12:00:01 bridges: mi:muz:bridgeESPS3-xxxxxxxxxxx (ch 7, fw 0.1.3)
12:00:01   port 1: (no label) model=basic mi:muz:conESP32C6-yyyyyyyyyyy
12:00:05 mi:muz:conESP32C6-yyyyyyyyyyy: 90 3c 64
12:00:05 mi:muz:conESP32C6-yyyyyyyyyyy: 80 3c 00
```

`90 3c 64` は Note ON（Note Number 60、Velocity 100）、`80 3c 00` は Note OFF です。

## ステップ 6：ラベルの設定

ラベルは、クライアントに付ける名前です（たとえば `left` や `drums`）。ラベルはクライアントに保存され、コンソールにも表示されます。同じモデルのクライアントが複数あるとき、アプリケーションはラベルでクライアントを区別できます。

1. **Console** のページで、ブリッジの **Clients** タブを開き、クライアントの行をクリックします。
2. **Settings** の **Label** にラベルを入力し、**Set** を押します。使える文字は `A-Z a-z 0-9 - _ .` で、30 文字までです。

設定は、ブリッジを経由して無線でクライアントに送られます（`port 1 set label left`）。設定とコマンドの一覧は、[設定コマンドと SysEx](../config-commands.md)（英語）を参照してください。

## ステップ 7：ブリッジなしでの接続（BLE-MIDI）

クライアントは、ペアリングしたブリッジに接続できないとき、`mi:muz:conESP32C6-<固有 ID>` という名前の BLE-MIDI デバイスとして動作します。PC やタブレットからは、一般的な BLE-MIDI デバイスと同じように接続できます。BOOT ボタンと LED の動作は、ブリッジ経由のときと同じです。

注意点は以下の通りです。

- ペアリング済みのクライアントは、BLE-MIDI で待機している間も 20 秒ごとにブリッジを探し、見つかると ESP-NOW での接続に戻ります。
- ブリッジは電源を入れてから約 15 秒経たないとクライアントを受け付けないため、ブリッジを先に起動してください。
- macOS では、最初に BLE-MIDI で接続するときに「アクセサリの接続を許可」の表示で止まることがあります。
