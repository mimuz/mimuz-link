# mimuz-link API reference

| Document | For |
|---|---|
| [Web driver API](js-driver.md) | Web pages and Node.js programs that use bridges and clients (`mimuz-link.mjs`): finding clients, MIDI, config commands. The base of the device drivers. |
| [Arduino library API](arduino-library.md) | Firmware of clients (XIAO ESP32-C6) and bridges (XIAO ESP32-S3) built on the `mimuz-link` library. |
| [Config commands and SysEx](config-commands.md) | The setup commands of bridges and clients (USB serial, SysEx over USB-MIDI, relayed over the radio) and the SysEx messages of the bridge. |

These pages are also shown in the web console (**API reference**), from the same files.

Overview, building and the PC tools: [the top README](../README.md).
