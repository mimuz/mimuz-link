Chrome / Edge で http://localhost:3000 を開く（Safari は Web MIDI 非対応）。初回は MIDI の許可を求められる。
「イベント時刻→表示処理」は、ブラウザが MIDI を受け取った時刻（event.timeStamp）からこのページの処理が始まるまでの時間。ブラウザ内部の遅れの目安。
音を鳴らすと、Mac のオーディオ出力の遅延（数〜十数 ms）が上乗せされる。見た目だけで判断したいときはオフにする。
連射で押していた時間が 1 フレームより短くても見えるよう、パッドは Note On から最低 80ms 光らせている（押していた時間の表示は実測値）。
