Console Firmware uploader API reference

This browser has no Web Serial (needed for clients attached over USB and for the firmware uploader). Use Chrome or Edge, and open the page from http://localhost.

Bridges on USB-MIDI appear by themselves. Use "Load device" for a client attached over USB (or a bridge's serial port, for its log).

Devices

    A serial port can be open in one program only: close it here before using the PC tools or the firmware uploader on the same device. MIDI ports can be shared.
